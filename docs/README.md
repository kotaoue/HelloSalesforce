# docs

Salesforceから取得した情報が入るディレクトリ
Salesforce is 何？ を考えた情報は[workbooks](../workbooks/)

## ファイル・ディレクトリ一覧

| パス | 説明 |
| --- | --- |
| field-definitions.json | Salesforce Tooling API の [FieldDefinition](https://developer.salesforce.com/docs/atlas.en-us.api_tooling.meta/api_tooling/tooling_api_objects_fielddefinition.htm) でオブジェクトを全件取得した結果 |
| field-definitions.csv | 同上のCSV |
| objects/ | オブジェクトごとの FieldDefinition ファイル |
| actions/ | [kotaoue/salesforce-field-inspector](https://github.com/kotaoue/salesforce-field-inspector)を使用して取得した、オブジェクトごとの FieldDefinition ファイル |
